# __Portfolio Website__

Created Portfolio Website to present cumulative projects, experience, personal summary, and more. Portfolio Website includes:

1. Resume
2. Contact
3. Experience
4. Github Commits Log
5. Proficiencies/skills
6. Personal Portfolio of Current Projects

__Website Specifications__

* Utilized Github Pages to first build and upload the site with HTML, CSS, and JavaScript. Hosted through static Github Pages was insufficient for domain purposes, back-end support, and analytics.
  * Pointed Domain IP Address over to Network Solutions to Host unique domain name. Once hosted from Static Github Pages over to unique domain, implemented Web3 Forms for Contact submissions at bottom of page.
 

* Created Github Commits on website through Github Actions, which updates commit count automatically at midnight, removing the need for manual updates. This was done through GraphQL API.
